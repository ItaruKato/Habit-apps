# HaBiTa（iPhone 対応 習慣トラッカー）

毎日の習慣を記録して、連続記録（ストリーク）を伸ばすためのシンプルなアプリです。
iPhone の Safari で開いて「ホーム画面に追加」すると、通常のアプリのように全画面・オフラインで使えます。
App Store や Mac / Xcode は不要です。

## 主な機能

- **今日の習慣チェック** … タップで完了。「水を8杯」のような回数目標にも対応（−ボタンで取り消し）
- **くり返し設定** … 毎日 / 平日 / 週末 / 任意の曜日
- **連続記録・最高記録・30日達成率** を自動計算（予定のない曜日は連続記録を途切れさせません）
- **直近7日のストリップ** … 過去の日を選んで付け忘れを記録
- **ヒートマップ（直近18週）** と **月カレンダー** … カレンダーをタップして記録を修正
- 全部終わると紙吹雪でお祝い 🎉
- アイコン（絵文字）・カラーのカスタマイズ、ダークモード対応
- **バックアップの書き出し / 復元**（JSON。iPhone では共有シートから「ファイル」に保存可能）
- データは端末内（localStorage）のみに保存。外部送信なし

## iPhone で使う手順

### 1. 公開する（GitHub Pages・無料）

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. **Build and deployment → Source** を「Deploy from a branch」にする
3. Branch を `main`（フォルダは `/ (root)`）にして **Save**
4. 数分後に `https://<ユーザー名>.github.io/Habit-apps/` で公開されます

> Service Worker（オフライン機能）は HTTPS が必要なため、GitHub Pages などの HTTPS ホスティングで公開してください。

### 2. ホーム画面に追加する

1. iPhone の **Safari** で上記 URL を開く
2. 画面下の **共有ボタン（□に↑）** をタップ
3. **「ホーム画面に追加」** → 「追加」
4. ホーム画面の「HaBiTa」アイコンから起動

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み・iPhone 用メタタグ |
| `styles.css` | デザイン（iOS 風、ライト / ダーク） |
| `app.js` | アプリ本体（データ管理・集計・描画） |
| `manifest.webmanifest` | ホーム画面アプリとしての設定 |
| `sw.js` | オフライン対応の Service Worker |
| `icons/` | アプリアイコン |

ビルド不要の素の HTML / CSS / JavaScript です。

## ローカルで試す

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く（同じ Wi-Fi の iPhone からは http://<PCのIP>:8000）
```

## 注意点

- データは「その端末のその Safari / ホーム画面アプリ」の中に保存されます。機種変更の前に **設定 → バックアップを書き出す** を行ってください。
- ホーム画面に追加せず Safari のタブで使い続けると、iOS の仕様で長期間使わないとデータが消える場合があります。ホーム画面への追加をおすすめします。
- 更新を公開したら `sw.js` の `CACHE` のバージョン（`habita-v3` など）を上げると、確実に新しいファイルに切り替わります。
